Platform Architecture

Sky-Dock Mothership

성층권 장기 체공을 위한 수소연료전지 기반 대형 무인항공기. 하부 도킹 베이에서 10대의 Gold-Runner를 동시에 서비스합니다.

🛸

Mothership Airframe

날개 길이 85m, 전장 45m의 CNF/PEKK 복합소재 기체. 태양전지 패널(상부 날개)과 수소연료전지를 결합한 하이브리드 추진으로 성층권에서 72시간 이상 무착륙 체공합니다.

  • • Wingspan: 85m (CNF/PEKK Composite)
  • • Propulsion: H₂ Fuel Cell 2MW × 4
  • • Solar Array: 1,200m² GaAs Triple-Junction
  • • Endurance: 72+ hrs continuous
🔧

Docking Bay System

하부 동체에 배치된 10기의 자동화 도킹 포트. Gold-Runner가 접근하면 LiDAR/비전 기반 정밀 유도 시스템이 자동 도킹을 완료합니다. 도킹과 동시에 LH2 카트리지 교체와 충전이 병렬로 시작됩니다.

  • • 10× Automated Docking Ports
  • • LiDAR + Vision Guided Approach
  • • Magnetic Lock + Mechanical Latch
  • • Full Service Time: ≤ 3 min

LH2 카트리지 규격

각 카트리지는 이중벽 진공 단열 구조로 -253°C의 액체수소 15kg을 저장합니다. 자동 퀵-릴리즈 메커니즘으로 로봇 암을 통한 무인 교체가 가능하며, 빈 카트리지는 모선 내부에서 재충전됩니다.

🤖 Robotic Swap Mechanism

6축 로봇 암이 도킹된 Gold-Runner의 연료 베이에서 소진된 카트리지를 자동 추출하고, 사전 냉각된 만충 카트리지를 정밀 삽입합니다.

  • • 6-Axis Cryo-Rated Robotic Arm
  • • Quick-Release Bayonet Lock
  • • Auto Purge (He gas) Before Swap
  • • Leak Detection: ≤ 1×10⁻⁶ mbar·L/s
  • • Thermal Pre-conditioning (-250°C)
  • • Onboard Electrolyzer for LH2 Refill
Ultra-Fast Charging

500kW Stratospheric Charging

LH2 카트리지 교체와 동시에 진행되는 초고속 배터리 충전 — 도킹 3분 안에 모든 서비스 완료

Charging Architecture

모선의 수소연료전지(8MW 총출력)에서 생산된 전력을 DC 2,000V 버스를 통해 각 도킹 포트로 분배합니다. 도킹 커넥터를 통해 500kW가 Gold-Runner의 LiS 배터리팩으로 직접 공급됩니다.

Safety Systems

성층권의 극한 환경(-56°C, 5.5kPa)에서의 안전한 수소 취급과 고전력 충전을 위한 다중 보호 시스템.

  • • H₂ Leak Sensor Array (ppb level)
  • • Auto Vent System (성층권 안전 방출)
  • • Triple-Redundant BMS per Port
  • • Arc Fault Detection (AFD)
  • • Emergency Undock: ≤ 0.3 sec
  • • Cryo-Isolation Bulkhead (MLI)
