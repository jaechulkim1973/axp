Hybrid Architecture

Dual-Mode Mothership

가스터빈 연료 급유(Fuel Line)와 배터리 초고속충전(Power Line)을 단일 엄빌리컬로 통합 공급

TIER 1 — MOTHERSHIP TANKER

공중 급유/발전 플랫폼

Jet-A1/SAF 연료 탱크 8,000L + 수소연료전지 1MW + LiS 배터리 4.5MWh 탑재. 고도 3,000m에서 체공하며 10개 듀얼 포트로 연료+전력을 동시 분배.

TIER 2 — UMBILICAL LINE

통합 엄빌리컬 케이블

내부에 연료관 (ID 12mm)과 전력선 (1,500V/250A)을 동축 구조로 통합. 단일 커넥터로 도킹 즉시 급유+충전 동시 개시.

TIER 3 — GOLD-RUNNER 수급부

연료 수급 + 수전 인터페이스

기체 상부 자동 도킹 포트에서 연료는 터빈 연료계통으로, 전력은 DC-DC 컨버터를 거쳐 배터리팩으로 동시 공급. BMS/FMS 통합 관제.

Integrated Umbilical Cable

연료관 + 전력선 + 냉각 + 데이터를 단일 케이블에 통합한 항공용 엄빌리컬

FUEL 연료 이송관

내경 12mm 스테인리스 316L 튜브 + PTFE 라이닝. Jet-A1/SAF 대응, 최대 유압 10 bar, 유량 15 L/min. MIL-DTL-27422 드라이 브레이크 커플링으로 무누출 자동 분리.

ELEC 고전류 전력선

그래핀-구리(Gr-Cu) 합금 도체 95mm², 1,500V DC / 250A. 전기전도도 구리 대비 130%, 중량 대비 전류밀도 2.5배. Fluorinert FC-3283 액냉으로 도체 온도 65°C 이하.

🛡️ 보호 외피 + 데이터 라인

CNF/PEKK 편조 차폐 + 그래핀 코팅 외피. EMI 차폐 60dB, 인장강도 1,200N. 광섬유 데이터 라인(10Gbps) 내장. 총 중량 0.85 kg/m, 정전기 방지 처리.

Safety & Fail-Safe Systems

🛢️

Fuel Safety

  • • 드라이 브레이크 커플링 — 분리 시 연료 누출 zero
  • • 이중 차단 밸브 + 유량 센서 실시간 감시
  • • 연료관 불활성 가스(N₂) 퍼지 시스템
  • • 정전기 방지 본딩 와이어 내장
  • • OBIGGS(기내 불활성 가스 생성장치) 적용
⚡

Electric Safety

  • • 과전류 차단기(SSPC) + 아크 결함 감지(AFD)
  • • 절연 모니터링 — 연료관/전력선 간 이격 ≥15mm
  • • 긴급 자동 분리(Emergency Release) ≤0.5초
  • • 온도 퓨즈 다중 배치 (75°C 트립)
  • • 연료/전력 격벽 이중 실드 구조

Operational Modes

🔄

Mode A — 순환 급유

5대씩 교대 도킹. 6분 동시 급유+충전 → 50분 비행. 연속 순환 체계로 무제한 작전 영역 확보.

🔗

Mode B — 테더 비행

엄빌리컬 연결 상태 비행. 연료+전력 실시간 공급, 반경 200m 내 무제한 체공. 장기 감시 임무.

⛽

Mode C — 연료 전용

배터리 충분 시 가스터빈 연료만 급유. 3분 이내 급유 완료. 고속 순찰 작전에 최적화.
